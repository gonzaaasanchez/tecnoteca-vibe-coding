¿Qué es una base de datos?

📖 DB = Database = Base de datos — los tres términos significan lo mismo

Es como una planilla de Excel en la nube, pero tu app puede leerla y escribirla en tiempo real, desde cualquier dispositivo.

📋 Sin DB
  • Los datos se pierden al cerrar
  • Solo funciona para un usuario
  • No hay historial
🗄️ Con DB
  • Los datos persisten siempre
  • Múltiples usuarios simultáneos
  • Historial y consultas
🧩 La analogía

Tu app es el negocio.
La base de datos es el depósito donde guardás el stock, los clientes y los pedidos.

Sin depósito, cada vez que abrís el local empezás de cero.

¿Qué es una API?

Es el canal de comunicación entre tu app y la base de datos (o cualquier servicio externo). Como el mozo que lleva el pedido a la cocina y trae el resultado.

📱
Tu app
Hace una pregunta o pide un dato
→
🤵
La API
Lleva la solicitud y trae la respuesta
→
🗄️
Base de datos
Guarda, procesa y devuelve la información
🔑 Las API keys son como llaves de acceso — nunca se comparten públicamente
⚡ Hoy usamos Supabase: DB + API en un solo lugar, gratis

Bonus 25 minutos

📅 Turnero — reservar, ver y gestionar turnos

📋 Prompt para v0
Quiero un sistema de turnos para mi negocio. Que muestre los días y horarios disponibles, y que el cliente pueda elegir uno, poner su nombre y reservarlo. Los turnos ocupados tienen que verse diferente para que no se puedan volver a reservar.
💡 ¿Qué aprenden?
  • Leer y escribir la DB en la misma pantalla
  • Actualizar un registro existente (UPDATE)
  • Mostrar estados visuales en tiempo real
  • Que la DB es la "fuente de verdad" compartida
🚀 El momento "magia"

Un alumno reserva un turno desde su celular y otro alumno ve cómo cambia a rojo en tiempo real desde su computadora.

📌 Ideal para: peluquerías, médicos, clases particulares, talleres

Cierre técnico 15 minutos

Publicar la versión con base de datos

1
Revisar que todo funcione en v0Login, productos y formulario — probar el flujo completo
2
Agregar las variables de entorno en VercelSettings → Environment Variables → pegar URL y Key de Supabase
3
Deploy desde v0La app se actualiza con la nueva versión conectada a la DB
4
Probar con el link realRegistrarse, ver productos y enviar una consulta desde el celular
⚠️ Variables de entorno

Las keys de Supabase no van en el código. Van en las variables de entorno de Vercel para que nadie las vea.

✅ Checklist final
  • Registro y login funcionan
  • Productos cargan desde la DB
  • Formulario guarda en Supabase
  • URL pública compartida con el grupo
